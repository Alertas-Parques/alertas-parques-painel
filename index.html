Configuração (só neste aparelho)

A página precisa de um token do GitHub para ler e salvar o alertas.yaml. O token fica guardado só neste navegador.

  1. Abra github.com → novo token (fine-grained) e entre na sua conta.
  2. Resource owner: Alertas-Parques. Expiration: 30 dias. Repository access: Only select repositories → alertas-parques.
  3. Permissions → Repository → Contents: Read and write. Gere o token e copie.
  4. Se aparecer que o token aguarda aprovação: na organização, Settings → Personal access tokens → Pending requests, aprove o seu pedido.
  5. Cole abaixo e toque em Salvar.
