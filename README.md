# Painel dos Parques

Página para ver filas ao vivo e mudar, pelo celular, os alertas do repositório privado `alertas-parques`.

Abra: https://alertas-parques.github.io/alertas-parques-painel/

Esta página não guarda nenhum dado: os alertas ficam no repositório privado, e o token do GitHub
fica só no navegador de quem usa. Filas: API pública do ThemeParks.wiki.
